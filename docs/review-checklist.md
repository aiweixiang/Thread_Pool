# 交付前自检

> 这是动作清单，不保存风险状态。风险状态和原因只查 `docs/pitfalls.md`。
> 每项写“通过 / 不适用 / 需讨论”。

## 开始前

- [ ] 已阅读 `AGENTS.md` 和 `docs/pitfalls.md` 中的相关风险。
- [ ] 明确本次改动涉及的公开语义、兼容性和回滚方式。
- [ ] 若涉及 P17、P18、P20、P24-P33，先确认前置条件和范围。

## 构建与测试

- [ ] Release 构建无警告。
- [ ] `ctest` 全部通过。
- [ ] 并发改动已跑 TSan。
- [ ] 内存或生命周期改动已跑 ASan/UBSan。
- [ ] 测试没有依赖固定 `sleep_for` 完成同步。
- [ ] 新修复有回归测试；无法复现的风险有结构性检查。
- [ ] 失败计数可从工作线程安全更新，或明确限定为主线程。

## 行为不变量

- [ ] `submit()` / `try_submit()` 的返回类型和失败入参语义未变。
- [ ] P17：任务对象仍不可复制/移动；若引入搬动，已完成 promise 改造。
- [ ] P18：若移动任务构造，已保住有界队列语义、ID 回滚和锁外通知。
- [ ] `wait()` 仍只等待调用时刻前成功提交的任务。
- [ ] 并发 shutdown 仍是第一个模式生效，并等待所有 worker join。
- [ ] Discard 任务仍在锁外析构，所有 notify 仍在解锁后。
- [ ] 任务异常仍可通过 `future.get()` 观测。
- [ ] 用户可见语义变化已同步头文件顶部和 README。

## CMake / CI / 安装

- [ ] `cmake --install` 安装内容与声明一致。
- [ ] 若修改导出或 package，安装后 consumer 可以构建。
- [ ] CI 覆盖普通测试、TSan、ASan/UBSan。
- [ ] 若适用，demo 已被执行而不只是编译。
- [ ] 警告策略和编译器矩阵与项目声明一致。

## 文档与版本

- [ ] `docs/pitfalls.md` 是唯一风险状态来源；没有在别处复制状态表。
- [ ] `docs/requirements.md` 与实际行为一致。
- [ ] 用户可见变化已更新 `CHANGELOG.md`。
- [ ] 发布时版本号、tag 和安装产物一致。
